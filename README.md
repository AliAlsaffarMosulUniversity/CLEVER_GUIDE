# حقيبة الحاسوب

تطبيق لطلبة المرحلة الثانية، قسم إدارة الأعمال، كلية الإدارة والاقتصاد، جامعة الموصل.

مادة: تطبيقات إدارية باستخدام الحاسوب.

ملخصات الفصول العشرة، اختبارات، بطاقات مصطلحات، أدوات تدريب، واجبات، وأسئلة الطلبة للمحاضرة.

الدخول بالبريد الجامعي فقط.

تصميم وبرمجة: الأستاذ علي الصفار
